Proyecto 1: Sistema de Gestión de Ventas

2026

Desarrollo de un sistema de gestión de ventas orientado a organizar y administrar información relacionada con clientes, productos y transacciones comerciales. El proyecto permitió aplicar conocimientos de diseño y manejo de bases de datos, utilizando consultas SQL para registrar, consultar, actualizar y administrar la información almacenada. También se trabajó en la identificación de relaciones entre las diferentes entidades del sistema y en la creación de consultas para obtener información específica, como clientes, ventas y productos. Este proyecto permitió fortalecer las habilidades en bases de datos, análisis de información, lógica de programación y resolución de problemas mediante herramientas tecnológicas.


Proyecto 2:Página Web de Hoja de Vida

2026

Diseño y desarrollo de una página web personal destinada a presentar de manera organizada el perfil profesional, formación académica, experiencia, habilidades y proyectos realizados. Para su construcción se utilizaron tecnologías como HTML y CSS, aplicando estructuras semánticas, estilos personalizados y diferentes elementos de diseño para mejorar la presentación de la información. El proyecto permitió fortalecer conocimientos relacionados con la creación de interfaces web, organización del contenido, estructura de páginas, diseño visual y adaptación de los elementos para ofrecer una experiencia de navegación clara y sencilla. Además, permitió poner en práctica conceptos fundamentales del desarrollo frontend.


Proyecto 3: Aplicaciones y Ejercicios de Programación

2025

Desarrollo de diferentes programas y soluciones informáticas orientadas a fortalecer los fundamentos de programación y el pensamiento lógico. Durante el proyecto se trabajó con variables, operadores, estructuras condicionales, ciclos repetitivos, arreglos, matrices y diferentes métodos para almacenar y procesar información. También se realizaron ejercicios enfocados en la búsqueda, modificación y organización de datos, permitiendo desarrollar habilidades para analizar problemas y convertirlos en soluciones mediante algoritmos. Este proceso contribuyó al fortalecimiento de la lógica de programación y sentó bases importantes para el desarrollo de aplicaciones y proyectos de software de mayor complejidad.
